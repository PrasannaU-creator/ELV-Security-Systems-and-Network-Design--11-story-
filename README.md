# Two 11-Story Buildings – CCTV & ELV Network Design

## Project Overview

Conceptual network and ELV design for two 11-story buildings incorporating:

- 88 Hanwha IP CCTV cameras
- 44 Stentofon/Zenitel VoIP intercoms
- 44 access-control panels
- 6 IDFs
- 2 MDFs
- 6 × 48-port Cisco PoE access switches
- OM4 LSZH fiber backbone
- 24F Corning ALTOS inter-building fiber
- Primary and secondary 10G IDF uplinks
- Primary and secondary 25G inter-building uplinks
- CCTV, ACS, Intercom, UPS and PA VLAN segmentation
- Inter-VLAN routing at the core
